## What it does

`main.ts` writes one short, funny rant to `/output/entry.txt`: a furious
complaint about a microwave that keeps beeping five times after it has
already finished heating the food. Three sentences, one line, 299
characters, plain ASCII. The rant is assembled from fixed parts, so every
run writes exactly the same bytes.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22 or later. No dependencies, no network, no secrets.
